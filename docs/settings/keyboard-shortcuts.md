# Keyboard shortcuts

Technical reference for **Settings / Keyboard shortcuts**. The app shows a short summary;
this page keeps the full detail.

## Shortcut editor (page help)

Record a qualified chord or enter one explicitly. Each Save applies only its own field. Conflicting
chords and protected editing or system chords are rejected; the value `none` disables an optional
shortcut. The Voice shortcut uses the same binding here and on the Voice dictation page.

## Page intro

Shortcuts respect IME composition and text editing. Terminal input belongs to its focused console, not
the chat.
